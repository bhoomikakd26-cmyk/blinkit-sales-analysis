# 🛒 Blinkit Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes Blinkit's grocery sales data using Power BI to provide meaningful business insights. The dashboard helps understand sales performance, customer ratings, outlet performance, and product trends through interactive visualizations.

---

## 🎯 Business Objective

The objective of this project is to analyze Blinkit's sales performance and answer key business questions using an interactive dashboard.

The dashboard focuses on:
- Total Sales
- Average Sales
- Number of Items Sold
- Average Customer Rating
- Outlet Performance
- Item Type Analysis
- Sales Trend Analysis

- Sales
- Customer ratings
- Item visibility
- Fat content
- Outlet size

---

## 💡 Key Insights

- Supermarket Type 1 generated the highest total sales.
- Tier 3 outlets achieved the highest sales among all outlet locations.
- Regular-fat products contributed more to overall sales than low-fat products.
- Fruits & Vegetables and Snack Foods were among the top-performing product categories.
